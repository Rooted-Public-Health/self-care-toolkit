# Self-Care Toolkit

Interactive version of the Advancing a Healthier Wisconsin Self-Care Toolkit, created for the community project *Strengthening Minoritized CHW Capacity to Combat Secondary Trauma using Natural Approaches*, in partnership with the Medical College of Wisconsin and Lawrence University.

Use the 8 Dimensions of Wellness wheel to choose a starting area, then work through the six-step planner.

Answers stay in the browser on that device only. They are not uploaded to a server. On the last page, use **Download PDF** to save the completed toolkit.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Source

Toolkit adapted from the [Self Care Starter Kit](https://www.ualberta.ca/en/human-resources-health-safety-environment/media-library/health-and-wellbeing/mental-health/other/self-care-starter-kit---homewood.pdf) from the University of Alberta.
